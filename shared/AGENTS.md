# Общий слой — правила уровня shared

Этот файл читается, **только когда правка действительно трогает `shared/*`**.
Правка внутри одного модуля сюда не заходит.

Тронуть `shared/*` — значит сработал один из семи признаков расширения области
(корневой `AGENTS.md`, «AI context budget»). Дальше действуют правила ниже.

## 1. Патч-бамп всех модулей — обязателен

Пять из шести оболочек работают **cache-first**. Без подъёма версии
исправление не доедет до вернувшегося пользователя: он останется на старом
кэше, и ошибка будет выглядеть починенной, не будучи ею.

Исключение — **Клиндарий**: stale-while-revalidate, бамп ради доставки правки
`shared/*` ему не нужен.

Проверяет `check-shared-bump.mjs`. Ему нужна история git — на клоне
`--depth 1` пропускается с кодом 2. Цепочка подъёма — `docs/rules/release.md`.

## 2. Прекэш

Файл общего слоя, подключённый в разметке модуля, **обязан** лежать и в
прекэше его service worker'а. Отдельно проверяется пара `backup.js` →
`version.js`: любой модуль, подключающий `shared/backup.js`, обязан подключать
и `shared/version.js` — и в разметке, и в прекэше. Без этого резервные копии
уходят без версии, и потом не отличить, из какой сборки копия.

Проверяет `check-shared-precache.mjs` — сравнивает **имена файлов**, а не
строки путей: у Клиндария и Конгрессов списки записаны по-разному.

## 3. Свой кэш, не чужой

`caches.match()` без области видимости читает **все** кэши origin в порядке
создания и может вернуть чужой ответ. Во всех service worker'ах применён
паттерн `matchOwn()`. Проверяет `check-sw-cache-scope.mjs`.

Имя кэша **обязано** содержать версию, иначе записи переживут обновление.

## 4. Спящих компонентов быть не должно

Файл в `shared/`, который никто не подключает, — это не «задел на будущее»,
а мина: он расходится с реальностью и однажды будет подключён устаревшим.
Разбор — `docs/journal/gate.md`.

## 5. Что нельзя ломать

- `settings.accentColor` **никогда** не удаляется из данных — он живёт в
  резервных копиях.
- Версия объявляется ровно в одном месте — `shared/version.js`.
- Экранирование сведено в один слой: не добавлять второй
  (`docs/journal/security.md`).
- Клиндарий обязан открыться, даже если общий слой сорвался.

## 6. Живой прогон

Правка `shared/*` — единственный случай, когда **хаб тоже прогоняется вживую**,
а не только изменённые модули. Полный гейт обязателен.
