# Документы и данные — локальные правила

Читать вместе с корневым `AGENTS.md`.

## Особенности модуля

- **Своих данных нет.** Модуль редактирует общее хранилище `CWDB.templates`,
  поэтому в резервной копии представлен именно им.
- **Намеренно НЕТ блока `[data-module="documents"]`** в `shared/style.css`:
  модуль держит общую палитру хаба. Атрибут `data-module` на плитке при этом
  нужен — по нему хаб находит плитку и проставляет версию.
- Общий справочник собраний: что в него попадает — `docs/journal/documents.md`.
- Архив документов использует общий рендерер; у него две ловушки, обе описаны
  там же.
- Три тихих дефекта CSS (24.08.2026) разобраны в том же журнале — прежде чем
  чинить рамки или цвета, посмотреть туда.
