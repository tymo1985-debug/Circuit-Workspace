# Конгрессы — локальные правила

Читать вместе с корневым `AGENTS.md`.

## Устройство

14 ES-модулей, точка входа `js/main.js`. Словарь `i18n/dict.js` — 112 КБ,
читать только `grep` по ключу.

## Особенности модуля

- **Версия — `service-worker.js`, `APP_VERSION`.** Файл называется
  `service-worker.js`, а не `sw.js` (как у трёх других модулей).
- Cache-first: правка `shared/*` требует патч-бампа.
- **Затенение `t()` — отдельный класс багов этого модуля.** Локальная
  переменная или импорт с тем же именем перекрывает функцию перевода, и строки
  молча остаются непереведёнными. Ловится `check-i18n-shadow.mjs`, разбор — в
  `docs/journal/i18n.md`.
- **CSS вставляется строкой** из `plan-fit.js` и `printing.js` — при правке
  переменных помнить, что `check-css-vars.mjs` видит и этот CSS.
- `letterLanguage` — язык **письма**, не интерфейса. Путать нельзя.
- `settings.language` собственный, к общему слою не приведён: «язык документа»
  здесь ещё не подключён.
