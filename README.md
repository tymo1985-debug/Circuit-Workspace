# Circuit Workspace

PWA-хаб, объединяющий инструменты для организации районного служения под одним
интерфейсом, единым визуальным слоем и общей локализацией. Стартовый экран
(`index.html`) показывает плитки модулей; каждый модуль — самостоятельная папка
со своей версией, своим service worker'ом и своим хранилищем.

**Единственный источник правды — этот репозиторий.** Отдельные репозитории
модулей (`Assembly-Programm-`, `Circuit-Planner`, `Pioneer-School-Workspace`)
могут быть устаревшими: они годятся как источник новой логики конкретного
модуля, но никогда как основа итоговых файлов.

---

## Документация

Рабочие документы лежат в корне; подробности по темам — в подпапках `docs/`
(`journal/` — история решений, `rules/` — выпуск и доставка, `audit/` — аудиты,
`design-system/`, `design-tokens/`, `db-migration/`, `documents/`, `print/`,
`context/`, `changelog/`, `todo-archive/`).

| Файл | Что внутри | Когда открывать |
|---|---|---|
| `README.md` | Этот файл: обзор, структура, деплой | Первое знакомство с проектом |
| `ARCHITECTURE.md` | Устройство хаба, общий слой, модель данных, конвейер обновления | Перед изменением `shared/*` или добавлением модуля |
| `AGENTS.md` | Ядро правил для ИИ-ассистентов; история решений — `docs/journal/` | Перед любой задачей по коду |
| `ROADMAP.md` | Где проект сейчас и куда идёт | Планирование |
| `TODO.md` | Конкретные задачи: Inbox / Next / In Progress / Done (в Done только текущий месяц) | Ежедневная работа |
| `IDEAS.md` | Идеи без сроков и обязательств | Появилась мысль — записать сюда |
| `CHANGELOG.md` | Что и когда реально изменилось | После выпуска |
| `CLAUDE.md` | Инструкции для ИИ-ассистентов: как вести проект | При работе через Claude |

Короткое правило: **что делать** — в `TODO.md`, **как устроено** — в
`ARCHITECTURE.md`, **обо что не споткнуться** — в `AGENTS.md`.

## Структура репозитория

```
Circuit-Workspace/
├── index.html                 ← хаб: плитки модулей, версии читаются в рантайме
├── manifest.json, service-worker.js, icon-*.png, apple-touch-icon.png
├── shared/                    ← общий слой (меняется осторожно: затрагивает всех)
│   ├── style.css, theme.js     ← MD3-токены поверх фирменных --cw-* переменных
│   ├── db.js, backup.js        ← IndexedDB `circuit-workspace-db` и резервные копии
│   ├── i18n.js, i18n/common.js ← локализация (ru/uk/en/pl/de), общие словари
│   ├── update.js, offline-check.js, precache.js ← обновление и офлайн
│   ├── errors.js, dates.js     ← журнал ошибок, «сегодня» по местному времени
│   ├── version.js              ← CW_VERSION + CW_MODULES (единственный реестр версий)
│   └── fonts/, brand/, vendor/ ← шрифты, исходники иконок, библиотеки
├── congress-project/          ← Конгрессы (ES-модули, js/main.js — вход)
├── circuit-planner/           ← Клиндарий (монолитный app.js, IIFE)
├── pioneer-school/            ← Школа пионеров
├── appointments/              ← Назначения
├── documents/                 ← Документы (шаблоны писем)
├── journal/                   ← Журнал
├── archive/                   ← Архив (просмотр конвертов служебных годов и конгрессов)
├── scripts/                   ← гейт `check-*.mjs`, живые прогоны `live-*.mjs`
└── docs/                      ← журнал решений, правила, аудиты
```

Общие данные экосистемы лежат под ключами `cw-sender` (отправитель),
`cw-lang*` (язык интерфейса) и `cw-doclang*` (язык документа). Модуль никогда
не читает хранилище другого модуля.

Актуальные номера версий — только в `shared/version.js`. В этом файле и в
разметке хаба их намеренно нет, чтобы они не расходились с реальностью.

## Модули

| Папка | Название | Что делает | Хранилище |
|---|---|---|---|
| `congress-project/` | Конгрессы | Программа конгрессов, задания, письма участникам в PDF | localStorage `congress-pwa-v34-speakers` |
| `circuit-planner/` | Клиндарий | Календарь служебного года, посещения, маршрут, S-302 | localStorage `service-year-planner-v9-4-2` |
| `pioneer-school/` | Школа пионеров | Учащиеся, расписание, учебники, S-253, экспорт | IndexedDB (собственная база модуля) |
| `appointments/` | Назначения | Письмо о назначении и вычёркивании (uk/ru/de) | localStorage `cw-appointments-v1` |
| `documents/` | Документы | Шаблоны писем; своих данных нет | `CWDB.templates` |
| `journal/` | Журнал | Записи, связи, защищённые записи | IndexedDB `circuit-workspace-db` (хранилища `journal*`) |
| `archive/` | Архив | Просмотр конвертов; своих данных нет, конверты пишут модули-источники | — |

Когда-то планировавшийся модуль «Формуляр посещения» **исключён сознательно**:
его функционал полностью поглощён Клиндарием.

## Версионирование

`shared/version.js` — единственный реестр версий: `CW_VERSION` (хаб) и
`CW_MODULES` (модули). В разметке и в этом файле номеров нет. Цепочка подъёма,
исключения и патч-бамп при правке `shared/*` — `docs/rules/release.md`;
проверяет гейт.

---

## Деплой

GitHub Pages: Settings → Pages → Deploy from branch → `main` / root. Один URL
на весь хаб, модули открываются как подпапки того же сайта. После коммита
GitHub Actions прогоняет гейт (`node scripts/check-all.mjs`) и публикует
изменения.

---

## Локальный запуск

Service worker и `fetch` не работают по `file://`, поэтому нужен любой
локальный сервер:

```bash
python3 -m http.server 5173
# затем http://localhost:5173/
```
