# IDEAS

Идеи проекта без сроков и обязательств. Даже небольшая мысль должна быть
записана здесь. Решили реализовать — идея переезжает в `TODO.md`.
Идеи не удаляются без явной просьбы.

---

## Интерфейс

- **Переименовать мобильный слой Конгрессов.** `js/mobile.js`, `.mobile-bar`,
  `.mobile-menu`, `#mCongressBtn` описывают оболочку, которая с 4.31.0
  работает до 1100px и по кнопке — на любой ширине. Имена вводят в
  заблуждение. Переименование затрагивает `@media print`, четыре места в
  `styles.css` и разметку; делать отдельным заходом, не вместе с правкой
  поведения.

- **Плотный режим письма в «Назначениях»** — переключатель, ужимающий поля и
  межстрочные интервалы, когда список братьев длинный и письмо не помещается на
  одну страницу.
- **Предпросмотр печати прямо в модуле** вместо системного диалога, чтобы было
  видно разбиение на страницы до отправки на принтер.
- **Единый визуальный язык карточек и списков действий во всех модулях.**
  Приёмы, опробованные на карточке ближайшего визита в Клиндарии: главное
  число или статус вперёд отдельным акцентным чипом, заголовок вторым уровнем,
  метаданные приглушённым цветом, статусы тонированными плашками, действия в
  один столбец с иконкой слева. Всё это выражается уже существующими
  `--cw-*`/MD3-токенами и `Material Symbols`, отдельная библиотека не нужна.
  Требует ревизии экранов всех четырёх модулей и разбивки на фазы —
  разом не делать. Первый шаг сделан в Конгрессах 4.28.0 (список заданий на
  телефоне); приёмы оттуда — раскладка `<td>` через `order`, чипы вместо
  подписанных полей, действия по выбору строки — переносимы на остальные.
- **Мобильный вид Конгрессов перегружен и малоинформативен.** Сейчас
  `@media(max-width:680px)` разворачивает таблицу программы в «строка = блок»:
  каждое задание превращается в десять подписанных полей, где подпись («ЧАС»,
  «ХВ.», «РЕП.») длиннее самого значения, а тема — главное содержимое — имеет
  тот же вес, что и длительность. Плюс до программы нужно проскроллить четыре
  экрана служебного: сайдбар со списком конгрессов (вложенный скролл
  `max-height:340px` с красной кнопкой «Сбросить данные»), карточку из трёх
  полей и шесть кнопок действий подряд. Направление правки — не менять логику
  модуля, а перестроить мобильный слой: список конгрессов и поля конгресса —
  в шапку и bottom sheet, шесть кнопок — в меню «ещё» и FAB, строка задания —
  в карточку с иерархией (время + тема вперёд, статусы тонированными метками,
  действия по нажатию). Это частный случай пункта про единый визуальный язык
  карточек выше — делать в одной системе с ним, начиная с Конгрессов как
  самого тяжёлого экрана.

## Функции

- **История писем в «Назначениях»** — сохранять отправленные письма с датой и
  составом, чтобы было видно, кого и когда назначали.
- **Экспорт письма в PDF без системного диалога** (jsPDF, как в остальных
  модулях) — даст стабильное имя файла на всех платформах.
- **Список братьев и собраний из общей базы** — подстановка имён из
  `shared/db.js` вместо ручного ввода в каждом модуле. Сейчас каждый модуль
  ведёт свою историю ввода.
- **Поле пола у учащегося Школы.** Письмо-приглашение начинается «Дорогой брат
  / дорогая сестра», потому что различить некого: в карточке учащегося и в
  анкете пола нет. Автоматический выбор обращения потребует поля в
  `Students.DEFAULT_COLUMNS`, вопроса в `registrationSchema.js` и перевода
  новых строк — то есть тянет за собой отдачу текста носителям. Отдельная
  задача, сознательно не вошедшая в фазу 6.
- **Массовая выдача писем Школы** — «письма всем учащимся» одним действием.
  Композер сейчас работает с одним адресатом; пакетная выдача поднимает
  вопросы, которых у одиночной нет (один PDF на всех или файл на каждого, как
  дедуплицировать снимки в архиве).

## Архитектура

- **Общий помощник для раскрывающихся меню в Конгрессах.** `js/topbar-menu.js`
  и выпадающий список конгрессов в `js/mobile.js` повторяют одну механику:
  открыть/закрыть по триггеру, закрыть по действию внутри, закрыть по клику
  мимо, закрыть по Esc. Различаются только селекторами элементов и тем, что
  меню шапки умеет ещё и стрелки клавиатуры. Третье такое меню сделает дубль
  дорогим — тогда и вынести в `js/menu.js` с параметрами
  `{trigger, panel, itemSelector}`. Сейчас не сделано осознанно: рефакторинг
  рабочего кода шапки не входил в объём задачи про мобильный вид.
- **Рендерить `register.html` Школы пионеров из `registrationSchema.js`** —
  сейчас состав вопросов описан дважды, и править нужно оба места.
- **Выборочная выгрузка записей общего хранилища в резервную копию.**
  `shared/backup.js` умеет брать отдельные store общей базы, но не отдельные
  записи внутри store. С появлением архива документов (13.08.2026) это значит,
  что копия Клиндария везёт и снимки Конгрессов. Данные при восстановлении не
  теряются — секция `partial` сливается, — но файл копии растёт лишним. Решение:
  необязательное поле-фильтр в реестре (`sharedStores: { db: [{ store:
  'documents', where: { module: 'circuit-planner' } }] }`). Делать не раньше,
  чем архив начнут вести два модуля, и обязательно с проверкой в
  `check-backup.mjs`.
- **Единый слой печати.** У Конгрессов, Школы и Назначений своя реализация
  печати и своё именование файлов; общий помощник убрал бы дублирование.
- **Наращивать `check-all.mjs` по следам повторяющихся багов.** Каждый класс
  ошибок, который уже рецидивировал, дешевле поймать скриптом, чем глазами.
  Кандидаты по убыванию доказанности:
  дрейф `@media print` (старый селектор топбара после переименования класса —
  били все четыре модуля); коллизии i18n-ключей (последний выигрывает молча,
  нужна AST-проверка дублей); вымывание файлов после drag&drop-загрузки на
  GitHub (наличие `shared/version.js`, всех `*/index.html`, всех `sw.js`);
  рассинхрон whitelist `_sanitizeForFont` и cmap субсета шрифта;
  подписи PDF, вылезающие за правое поле на длинных языках.
- **Единый вход хаба вместо PIN-защиты Клиндария** — или наоборот, PIN на
  уровне хаба для всех модулей. Решение не принято.
