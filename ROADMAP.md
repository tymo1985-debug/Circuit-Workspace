# Roadmap

Крупные вехи. Конкретные задачи — в `TODO.md`, идеи — в `IDEAS.md`.

---

## Current Version

Хаб v0.18.0 — четыре модуля под одной оболочкой.

- Хаб, Конгрессы, Клиндарий, Школа пионеров и Назначения работают на общем
  визуальном слое (MD3 поверх фирменной палитры) и общей локализации
  (ru/uk/en/pl/de).
- Версии всех модулей читаются из единого реестра `shared/version.js`.
- У каждого модуля собственный офлайн-кэш, не конфликтующий с соседними, с
  именем, привязанным к версии модуля: выпуск гарантированно доезжает до
  пользователя, а не остаётся в кэше навсегда.
- Обновление приложения — общий слой `shared/update.js`: полоса «Доступна
  новая версия» с выбором пользователя вместо внезапной перезагрузки, и одна
  кнопка в шапке хаба, обновляющая хаб и все четыре модуля разом.

## Next Version

Общий слой данных перестаёт быть только проектом.

- Отправитель (имя, код района, адрес, контакты) переезжает в `shared/db.js`;
  Конгрессы, Клиндарий и Назначения перестают хранить три копии одних данных.
- «Язык документа» становится отдельной настройкой рядом с экспортом — граница
  между языком оболочки и языком печатной бумаги закрепляется в интерфейсе.
- Реальные переводы шаблонов писем Конгрессов для `ru` и `de`.

## Future

- **Единый слой печати `shared/print.js`.** У Конгрессов, Школы и Назначений
  своя реализация печати. Один и тот же баг — `@media print` с устаревшим
  селектором топбара, из-за чего шапка попадает на бумагу — рецидивировал
  уже в четырёх модулях. Общий слой закрывает класс багов целиком, а не по
  одному. Цена: правка `shared/*` при четырёх разных вёрстках печати —
  нужны мокапы и патч-бамп всех модулей. Две-три сессии.
- Перевод Конгрессов и Клиндария с localStorage на `shared/db.js` без потери
  данных пользователей. **Предпосылка общего справочника собраний** — без
  этого шага справочник не поедет. Отдельно учесть: `restoreDb` делает
  `store.clear()` и снесёт общие данные, нужны `sharedDepends` в реестре
  модулей и `BroadcastChannel('cw-directory')` для синхронизации вкладок.
  Несколько сессий, каждая фаза — с подтверждением.
- **Общий слой документов: шаблоны перестают жить в настройках модулей.**
  Архитектура принята 11.08.2026 (`docs/documents/00-proposal.md`), код не
  начат. Сейчас в проекте три независимых механизма документов с тремя
  диалектами плейсхолдеров, около 14 КБ прозы в коде и до двенадцати
  редактируемых копий текстов у каждого пользователя Клиндария; истории
  отправленных писем нет вовсе. Порядок: сначала `shared/templates.js` — движок
  и единый справочник переменных, без изменения хранилища; затем перенос самих
  текстов в `CWDB` с `adopt()`; затем модуль «Документы» с библиотекой и одним
  общим редактором вместо двух; затем архив отправленных документов как
  неизменяемых снимков. Формуляры (S-302, S-253, анкета пионера) в этот трек
  не входят — у них фиксированная геометрия PDF, им место рядом с
  `shared/print.js`. Шесть фаз, каждая осмысленна сама по себе: остановка после
  любой не оставляет систему в полурабочем виде.
- Общие справочники собраний и людей: имя вводится один раз и доступно во всех
  модулях.
- Решение по единому входу: PIN-защита на уровне хаба вместо отдельного слоя
  Клиндария.
- Синхронизация данных между устройствами.
