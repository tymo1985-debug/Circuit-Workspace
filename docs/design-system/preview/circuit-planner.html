Самый рискованный модуль для переделки. CSS календаря живёт в инжектируемом блоке <style id="calendarViewStyles">, построен на !important и меряет --topbar-h / --calendar-side-top из живого DOM. Любая правка сетки календаря должна идти внутрь этого блока, а не в общий слой.

Что предлагается: унифицировать только оболочку — шапку, боковую панель, диалоги, поля. Сам календарь остаётся собственным компонентом модуля, но его цвета переводятся на --status-* (они уже существуют и взяты из модели данных этого же модуля: normal / important / critical).

Не трогать: ключ service-year-planner-v9-4-2, встроенный выбор цвета акцента (перезаписывать выбор пользователя нельзя — менять можно только значение по умолчанию для новых), PIN-слой.
