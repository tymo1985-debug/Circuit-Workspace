# 04 · Универсальная оболочка модуля

Живой макет: **`preview/shell.html`** — там же все служебные состояния и узкий экран.

---

## Зачем

Сегодня оболочек четыре:

| Модуль | Структура |
|---|---|
| Конгрессы | `header.topbar` + `main.layout` = grid(290px, 1fr) |
| Клиндарий | `aside.sidebar` + `main.main > header.topbar` + `nav.bottom-nav` |
| Школа | `div.app-shell > aside.sidebar + main.content > section.route > header.route-header` |
| Назначения | `header.topbar` + `div.app` |

Прямое следствие: `shared/nav.js` перебирает четыре селектора подряд (`.topbar .topbar-title-row` → `header.topbar` → `.topbar` → `.sidebar .brand`) и держит запасной FAB на случай, если не нашёл ни одного. Каждый новый модуль — либо пятый селектор, либо ручная настройка `window.CW_HOME_SLOT`.

---

## Схема

```
┌──────────────────────────────────────────────────────────────┐
│ ModuleTopbar                                    64px, липкая │
│ [←] [знак] Название                    [действия] [⋮]        │
│            v1.6.0 · Сохранено 14:22                          │
├══════════════════════════════════════════════════════════════┤ ← дорожка 2px, акцент модуля
│              │                                               │
│  SideNav     │  PageContainer            max 1280px          │
│  264px       │  ┌─────────────────────────────────────────┐  │
│              │  │ PageHeader: заголовок + основные кнопки │  │
│  Группа      │  ├─────────────────────────────────────────┤  │
│  ▸ Раздел    │  │ Banner (если есть состояние данных)      │  │
│  ▸ Раздел ●  │  ├─────────────────────────────────────────┤  │
│              │  │ FilterBar: поиск, чипы, плотность        │  │
│  Группа      │  ├─────────────────────────────────────────┤  │
│  ▸ Раздел    │  │ Toolbar: действия над содержимым         │  │
│              │  ├─────────────────────────────────────────┤  │
│              │  │ Содержимое: таблица / форма / календарь  │  │
│              │  └─────────────────────────────────────────┘  │
└──────────────┴───────────────────────────────────────────────┘
                              ↓ < 900px
                    SideNav → BottomNav внизу
                    боковые панели → шторки снизу
```

Ключевое отличие от текущего состояния: **шапка идёт поверх всей ширины**, сайдбар начинается под ней. Сейчас у Клиндария и Школы сайдбар идёт от самого верха, и кнопка возврата оказывается внутри сайдбара — то есть в разных модулях в разных местах.

## Слоты шапки

| Слот | Содержимое | Обязателен |
|---|---|---|
| 1 · Возврат | `.cw-home-btn`, ставит `shared/nav.js` | **да, во всех** |
| 2 · Знак | 32px, фон `--cw-module-container` | да |
| 3 · Название | из `module.<id>.title` в `shared/i18n/common.js` | да |
| 4 · Подстрока | версия + статус сохранения | да, скрывается < 600px |
| 5 · Действия | 2–4 кнопки-иконки, специфичные для модуля | нет |
| 6 · Переполнение | `more_vert` → меню | если действий больше 4 |

Название модуля берётся из локализации, **не из разметки** — иначе оно разойдётся с плиткой хаба. Версия читается из кода модуля, как сейчас.

## Что общее, а что своё

### Общее для всех четырёх модулей — без исключений

- `.md-topbar-v2` со всеми слотами.
- Кнопка возврата: позиция, поведение, подпись.
- `.md-page` + `.md-page__header`.
- `.md-toolbar`, `.md-filterbar`, `.md-search`.
- `.md-banner`, `.md-snackbar`, `.md-emptystate`, `.md-skeleton`, `.md-progress`, `.md-savestatus`.
- `.md-dialog`, `.md-sheet`.
- Поля, кнопки, чипы, статусы, переключатели.
- Поведение на узком экране: сайдбар → низ, панель → шторка, таблица → карточки.
- Тема, язык, фокус, плотность.

### Своё у каждого модуля

| Модуль | Уникальное |
|---|---|
| Конгрессы | сетка программы с разделами; предпросмотр письма (лист A4); диалог проверки программы |
| Клиндарий | **сетка календаря**; панель дня; признаки недели; выбор цвета акцента; PIN-слой |
| Школа пионеров | визард анкеты; карточки уроков; редактируемая таблица с динамическими колонками; импорт PDF |
| Назначения | живой предпросмотр письма с масштабом и контролем страниц |

Правило разделения простое: **если это встречается больше чем в одном модуле — оно общее.** Календарь есть только у Клиндария → остаётся его собственным компонентом. Таблица есть у троих → общая.

## Состояния оболочки

| Состояние | Что показываем |
|---|---|
| Загрузка модуля | `.md-progress` под шапкой + скелетоны на месте содержимого |
| Пустой раздел | `.md-emptystate` с кнопкой действия |
| Фильтр пуст | `.md-emptystate` с кнопкой сброса |
| Несохранённые изменения | `.md-savestatus[data-state="dirty"]` в шапке |
| Ошибка сохранения | `.md-savestatus[data-state="error"]` + `.md-banner--error` |
| Долгая операция | `.md-progress` + текст о том, что именно идёт |
| Офлайн | `.md-banner--info` — данные локальные, синхронизации нет |

## Как это ложится на `shared/nav.js`

После унификации перебор из четырёх селекторов сводится к одному: `.md-topbar-v2__lead` (вставка `prepend`). Запасной FAB `.cw-home-fab` **остаётся в стилях** — он нужен для модулей, которые ещё не мигрировали, и его нельзя удалять до самого конца перехода.

Порядок безопасен: `nav.js` учится искать новый слот **первым**, оставляя старые селекторы после него. Тогда мигрированные и не мигрированные модули работают одновременно, и переход можно делать по одному модулю.
