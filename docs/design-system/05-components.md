# 05 · Библиотека общих компонентов

Живая галерея со всеми состояниями: **`preview/components.html`**.
Черновик кода: **`proposed/cw-ui.css`**.

---

## О названиях

В запросе компоненты названы `AppShell`, `ModuleHeader`, `DataTable`, `EmptyState` и т.д. — по логике фреймворков. Проект на vanilla, без сборки, и «компонент» здесь = **класс CSS + договорённость о разметке**.

В проекте уже есть два префикса: `.cw-*` (фирменный слой, хаб и плитки) и `.md-*` (слой MD3, модули). Третий словарь сделал бы поиск по коду хуже, а не лучше. Поэтому новые компоненты получают префикс **`.md-*`** — не из чистоты идеи (`AppShell` не компонент MD3), а потому что последовательность здесь важнее точности термина.

Соответствие запрошенных имён и фактических классов — в таблице ниже.

## Правила для библиотеки

1. **Компонент без описанных состояний не принимается.** Обычное, наведение, фокус, нажатие, недоступное, загрузка, пустое, ошибка — что применимо.
2. **Ни одного хекса в компоненте.** Только токены. Исключение — бумага документов.
3. **Компонент не знает, в каком он модуле.** Индивидуальность даёт `--cw-module`, а не отдельные правила для каждого модуля.
4. **Разметка минимальна.** Если компонент требует четырёх вложенных `div`, он спроектирован неправильно.
5. **Мобильное поведение — часть компонента,** а не отдельный набор правил в модуле.
6. **Компонент появляется в библиотеке после второго применения,** не после первого. Календарь Клиндария существует в одном месте — он остаётся своим.

## Иконки: ограничение, о котором легко забыть

`shared/fonts/material-symbols-outlined-subset.woff2` — субсет **под конкретный список**:

> home, calendar_month, school, settings, add, close, check, menu, chevron_right, search, event, mail, group, dark_mode, light_mode, delete, edit, description, apps, person, notifications, filter_list, print, more_vert, arrow_back, download, upload

Все макеты в `preview/` используют **только** эти иконки — намеренно, чтобы концепт был реализуем без пересборки шрифта.

Иконки, которых не хватает по концептам и которые потребуют пересборки субсета (`pyftsubset`, ~18 КБ на текущий список):

| Иконка | Где нужна |
|---|---|
| `arrow_back_ios` / `chevron_left` | листание месяцев в Клиндарии (сейчас `chevron_right` отражается поворотом) |
| `content_copy` | дублирование задания в Конгрессах |
| `drag_indicator` | перетаскивание строк |
| `expand_more` | сворачивание разделов программы |
| `warning` | баннер предупреждения (сейчас `notifications`) |
| `today` | «перейти к сегодня» |

Решение по каждой — отдельно: либо пересборка субсета, либо обход через поворот/замену. Пересборка меняет размер файла и **требует бампа версии SW**, иначе вернувшийся пользователь увидит старый шрифт с пустыми квадратами.
