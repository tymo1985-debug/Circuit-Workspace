# Конгрессы (`congress-project`)

Макет: **`preview/congress-project.html`** · Версия на момент аудита: v4.20.0
Акцент: `#2f4bb0` → `#1a6a9e` (синий) · Знак: `event`

---

**1. Назначение экрана.** Планирование программы конгресса: задания по времени, участники, статусы, рассылка писем, печатный план. Основной пользователь — координатор, работающий подолгу с плотной таблицей и сверяющийся с бумагой.

**2. Структура интерфейса.** Шапка на всю ширину → сайдбар со списком конгрессов, сгруппированных по сериям → рабочая область: заголовок конгресса, баннер проблем, панель фильтров, панель действий, таблица программы.

Сайдбар остаётся — он работает и соответствует модели данных (серия → конгресс). Меняется группировка: заголовки серий становятся `.md-sidenav__group`, а не псевдо-заголовками с `font-weight: 800` (такого начертания в шрифте нет).

**3. Заголовок, навигация, действия.** Возврат в хаб — крайний слева. В шапке: знак, «Конгрессы», версия, статус сохранения; справа — язык документа, настройки, переполнение. Основные действия конгресса («Печать плана», «Письма») — в `PageHeader`, а не в шапке: они относятся к текущему конгрессу, а не к модулю.

**4. Рабочие панели.** Главное изменение — **разделение одной строки из десяти кнопок на три полосы**:
- `FilterBar` — поиск, чипы состояния («Все», «Без участника», «Ждут ответа»), переключатель плотности.
- `Toolbar` — «Задание», «Раздел», «Проверить программу».
- Таблица — липкая шапка, фиксированные ширины колонок, строки-разделы с фоном `--md-surface-container`.

**5. Иерархия действий.** Одно заполненное действие на экран — «Письма». «Печать плана» контурная. Действия строки — максимум две иконки (`mail`, `edit`), остальное в контекстном меню. Удаление — текстовое красное, никогда не заполненное.

**6. Иконки.** `event` (конгресс), `mail` (письмо), `print` (план), `check` (проверка), `add`, `edit`, `delete`, `description` (шаблон), `settings`. Все — в текущем субсете. Для сворачивания разделов программы понадобился бы `expand_more` — его нет.

**7. Пустой экран.** Первый запуск: иконка `event`, «Пока нет ни одного конгресса», объяснение роли серии, две кнопки — «Создать серию» и «Восстановить копию». Вторая важна: у модуля есть резервное копирование, и человек, переустановивший браузер, должен видеть путь к своим данным сразу.

**8. Загрузка.** Скелетоны строк таблицы при открытии конгресса. При «Все письма» — `.md-progress` с текстом «Формирование письма 4 из 12»: генерация PDF на 12 участников не мгновенна.

**9. Ошибки и предупреждения.** `.md-banner--warn` над таблицей: «У трёх заданий не назначен участник — письма для них не сформируются» с кнопкой «Показать» (включает фильтр). Результаты «Проверить программу» — список `.md-banner` в диалоге вместо текущих `.issue.warn` / `.issue.err` с хардкодом `#fdb022` / `#f04438`, которые не следуют тёмной теме.

Отдельный `.md-banner--info`: «Язык письма — украинский, интерфейс — русский». Это **не ошибка**, а намеренная архитектура (`letterLanguage` ≠ язык интерфейса), и интерфейс должен её объяснять, а не прятать.

**10. Узкий экран.** Сайдбар → нижняя навигация: Программа / Письма / Печать / Ещё. Таблица → карточки через `data-label`. Панель фильтров сворачивается в чипы + кнопку `filter_list`.

**11. Связь с хабом.** Синий акцент из иконки модуля — в дорожке под шапкой, знаке, активном пункте сайдбара, полосе выделенной строки. Пользователь нажал синюю плитку — попал на экран с синей дорожкой.

**12. Уникальное для модуля.**
- Сетка программы со строками-разделами (утро/день).
- Предпросмотр письма — лист A4 на тёмной подложке.
- Диалог проверки программы.
- Редактор шаблонов писем с плейсхолдерами.

## Границы: что нельзя трогать

| Что | Почему |
|---|---|
| `#printArea`, `.planPrint`, `.planHead`, `.planTable`, `.psection` | печатный план, свёрстан под бумагу |
| `.letter-page` (794×1123, паддинги 92/100/70) | лист A4 в предпросмотре и печати |
| `dialog[open]{display:none!important}` в `@media print` | фикс дублирования диалогов при печати |
| `noAssignmentNeeded()`, `isLetterable()` | логика фильтрации строк для писем |
| `DEFAULT_TEMPLATES` для `ru`/`de` | это копии украинского; в `TODO.md`, не дизайнерская задача |
