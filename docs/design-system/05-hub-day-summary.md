# Хаб — сводка дня (Ф5, разбор)

**Заведено 24.10.2026** — визуальный аудит, фаза Ф5. Разбор до кода: что
показывать на хабе и откуда брать данные. Решения Алекса — в конце.

---

## Цель

Хаб перестаёт быть только меню. Сверху — «Сегодня»: то, что требует
действия, каждое со своей кнопкой. Ниже — плитки модулей (как сейчас, с
фирменными значками). Пример — мокап «Сводка дня» в документе аудита.

## Главная развилка — откуда хаб берёт данные

Инвариант `ARCHITECTURE.md`, раздел 6: **ни один модуль не читает хранилище
другого модуля.** Состояния Клиндария и Конгрессов — большие записи в
хранилище `state` общей базы, у Школы — своя IndexedDB, у Журнала — четыре
хранилища. Их схемы меняются вместе с модулями.

| | A. Хаб читает базы модулей | B. Модули публикуют сводку (рекомендую) |
|---|---|---|
| Как | хаб знает схемы всех модулей и сам считает | модуль при каждом сохранении пишет маленькую запись `cw-summary:<модуль>`; хаб читает только её |
| Инвариант | нарушается | соблюдается — так же, как конверты Архива |
| Связность | любая правка схемы модуля ломает хаб молча | формат сводки — маленький договор, проверяемый скриптом |
| Свежесть | всегда точно | точно: данные меняются только внутри модуля, а он пишет сводку при сохранении; «сколько дней осталось» хаб считает сам от дат |
| Минус | — | до первого открытия модуля после выпуска сводки нет — карточка говорит «откройте модуль» |
| Скорость первой отрисовки | асинхронно, 4 базы | синхронно (localStorage, как `cw-sender`) |

Сводка — производные данные: в резервную копию не входит, при восстановлении
модуль пересоздаёт её при первом открытии.

## Что может быть в «Сегодня»

| Модуль | Карточка | Данные в сводке | Действие |
|---|---|---|---|
| Клиндарий | идущее посещение «день 3 из 6» или ближайшее «через 5 дней» | 5 ближайших посещений: название, тип, даты начала/конца, флаги письма и S-302; порог напоминания о письме | «Открыть в календаре» |
| Клиндарий | письма и S-302 к отправке: число и ближайшее | (то же — хаб считает по правилу `getUpcomingReminders`) | «Что отправить» |
| Конгрессы | ближайший конгресс: дата, «через N дней», ближайший срок (ответ/запись/репетиция) | конгрессы с датой ≥ сегодня: название, место, дата, сроки; число незаполненных заданий и неотправленных писем | «Открыть программу» |
| Школа | идёт / через N дней; регистраций X | даты школы из «Назначения», место, число регистраций | «Открыть школу» |
| Журнал | открытые и просроченные задачи | число открытых задач, просроченных (`dueDate` < сегодня), ближайший срок | «Задачи» |
| Хаб | состояние полной копии | уже есть у хаба (`cw-backup-nudge`) | «Сделать копию» |

Пустая карточка не показывается: нет ближайших посещений — нет карточки.
Если «Сегодня» пусто совсем — одна строка «Срочного нет».

## Решения Алекса

24.10.2026:
- **Данные — модули публикуют сводку** (вариант B).
- **Карточки — только Клиндарий: посещение** (идущее или ближайшее) **и

  «Настройках».
