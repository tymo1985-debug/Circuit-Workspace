# AGENTS.md

## Что это
Circuit Workspace — хаб-приложение: стартовый экран с плитками модулей
(календарь посещений, конгрессы, школа пионеров и др.). Клик по плитке
открывает соответствующий модуль внутри того же приложения.

## Стек
Vanilla JS, без фреймворков и сборки. Хостинг на GitHub Pages.

## Деплой
Zip → распаковка → drag&drop файлов в репозиторий на GitHub → commit →
GitHub Actions деплоит за 20–40 сек.
Присылать/получать нужно только новые/изменённые файлы, а не весь набор
каждый раз. Если старые файлы становятся не нужны — явно указывать, какие
удалить.

## Структура репозитория
- `/shared/style.css` — общие стили для всех модулей
- `/shared/db.js` — общий слой данных
- `/shared/nav.js`, `/shared/version.js` — кнопка «На главную» и версии хаба/модулей
- `/<module-name>/` — отдельная папка на каждый модуль в корне репозитория
  (`congress-project/`, `circuit-planner/`, `pioneer-school/`), без промежуточного `modules/`
- при правках одного модуля — присылать/получать только его файлы, а не
  весь проект

## Жёсткие правила
- Один репозиторий, не набор отдельных репозиториев на модуль
- Общий слой (`shared/`) не дублировать внутри модулей
- Версию каждого модуля хранить в одном месте внутри модуля, а на стороне
  хаба — в `shared/version.js` (`CW_MODULES`); в разметку версии не вписывать
- При правке любого модуля проверять и главную страницу хаба (`index.html`)
  вместе с её интеграциями (`shared/nav.js`, `shared/style.css`,
  `shared/version.js`), чтобы модуль и хаб не расходились

## Статус
Хаб реализован, все три модуля встроены и работают: Конгрессы (v4.18.1),
Клиндарий (v9.56.1), Школа пионеров (v1.3.2). Общий визуальный слой —
Material Design 3 поверх фирменных `--cw-*` токенов.
